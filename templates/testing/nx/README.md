# Nx selective-testing adapter

Inspect the installed Nx version and migration state before copying this example. Nx 24 selection is task-based; older/upgraded workspaces may retain project behavior. Audit transitive inputs, outputs, implicit/dynamic dependencies, shared tokens/assets, schemas, flags, routes, generated code, test harness, and lockfiles before narrowing.

Resolve the baseline from the last successful relevant validation on the intended branch. Missing history or graph errors widen. Generate a selected-spec manifest and compare Playwright collection with it; aggregate split targets may merely cache unselected leaf work and are not proof that mutable live tests were excluded. Live E2E is never cacheable.

Controlled selector fixtures must cover shared component, CSS token, public type, auth rule, API schema, queue payload, migration, flag, asset, lockfile, helper, additions/deletions/renames, stale maps, missing baselines, and dynamic dependencies. Prove both inclusion and exclusion.
