# run-the-loop — canonical home (agent-skills repo)

This repo's own convergence home. `/run-the-loop` reads it to run one verified, resumable fire that
advances the **Autonomous Product Development & Growth Operating System** and keeps the agent-skills
estate improving.

## One fire
1. **Orient** — read `OPERATING-PRINCIPLES.md` + resume from `CONVERGENCE.md`; never restart answered research.
2. **Fan out** (≤5 live workers / ≤6 subagents per wave) on disjoint slices from `BACKLOG.md` + every standing item in `SPECIAL-TASKS.md`.
3. **Converge** — normalize, run the repo gates (`bin/lint-all.sh`, `audit-*`, `validate-agents`).
4. **Adversarial-review + verify** — green before any claim.
5. **Reconcile** — update `CONVERGENCE.md` + append `ledger.ndjson`; replenish `BACKLOG.md`.
