## ADDED Requirements

### Requirement: Route typed engineering changes

The canonical verification skill SHALL link to a packaged TypeScript workflow
covering implementation, navigation, configuration, rules, release, and runtime
verification in supported generated skill projections.

#### Scenario: Open the TypeScript workflow from a generated skill

- **WHEN** an agent reads the static verification guidance in a generated skill
- **THEN** its link resolves to the packaged canonical TypeScript workflow
