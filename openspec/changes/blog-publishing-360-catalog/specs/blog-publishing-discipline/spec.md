# Blog Publishing Discipline

## ADDED Requirements

### Requirement: Progressive editorial orchestration

The system MUST provide a concise triggerable orchestrator and load only applicable A–L category guidance for research, writing, updating, designing, authoring, publishing, and measuring blog content.

#### Scenario: New SEO article

- **WHEN** an agent is asked to create a new SEO article
- **THEN** it loads topic, DataForSEO, evidence, writing, visual, component, SEO, publishing, security, and governance guidance needed for the configured workflow

### Requirement: Canonical shared ownership

The system MUST direct reusable themes/assets/components/editor/rendering/workflow capabilities to theme.tools and their executable Storybook documentation to ui.theme.tools.

#### Scenario: Missing article widget

- **WHEN** no installed shared component satisfies a justified article need
- **THEN** the agent extends the canonical shared package and Storybook rather than creating an untracked site-local duplicate

### Requirement: Honest evidence

The system MUST distinguish encoded policy, implemented runtime code, verified integration, configured live providers, and actual publication evidence.

#### Scenario: Missing DataForSEO credentials

- **WHEN** credentials or live receipts are unavailable
- **THEN** local contracts and fixtures may be implemented but keyword research and production eligibility remain blocked or unverified
