# Proposal

> **Architect:** Codex
> **Architect Role:** assigned

## Why

Editorial guidance is fragmented across SEO, site-generation, editor, and content skills while the shared theme.tools implementation expects a canonical blog-publishing skill that does not exist. Agents need progressive, exact A01–L30 guidance without loading 360 requirements into unrelated tasks or overstating live provider/runtime evidence.

## What Changes

- Add one concise blog-publishing orchestrator with twelve lazy category guides.
- Preserve the exact 360 authorized directives and their source references in a validated machine ledger.
- Add provenance, independent development/held-out evaluations, and deterministic catalog checks.
- Route blog/editorial work through the new skill and content pack while retaining existing specialist rules.
- Point runtime/shared UI work to theme.tools and ui.theme.tools rather than duplicating packages or components.

## Capabilities

### New Capabilities

- `blog-publishing-discipline`: research-driven article planning, evidence, composition, authoring, publication, measurement, and governance.
- `blog-publishing-traceability`: exact A01–L30 catalog validation, provenance, evaluation, and honest implementation state.

## Impact

Agent-skills instructions, router/content pack, schemas, tests, and evaluations only. This change does not claim theme.tools runtime completion, live DataForSEO access, publication, scheduling, or deployed behavior.
