## Architecture

1. **Ingress (`UserPromptSubmit`)**:
   - `bin/prompt-hydration-hook.mjs` pipes the user prompt into `bin/prompt-hydrator.ts` and `bin/skill-router.py`.
2. **Product Gap Audit & Categorical Saturation**:
   - `auditProductGaps(checkout, prompt)` inspects the checkout for missing or partial standard surfaces (`Settings & Preferences`, `Extensible Plugin Catalog`, `@theme.tools 28-Library Thin-Shell Binding`, `Cloudflare Worker & Custom Domain Config`, `100% Unit Coverage & Cloudflare Browser Run E2E`) and populates 5–10 categorical web-research/competitor expansion matrices.
3. **Right-Sized SCRUM Deliberation Quorum (`bin/scrum-deliberation-quorum.ts`)**:
   - Evaluates prompt and gap triggers against the 28-agent roster, convening only the 4–7 required specialists across `claude`, `codex`, and `gemini` to synthesize consensus decisions, a dissent register, and a 9-node OpenSpec task DAG (`task-graph.json`).
4. **Multi-Swarm Wave Compiler (`bin/multi-swarm-orchestrator.ts`)**:
   - Compiles topological execution waves with isolated worktree slots (`wt-*`), deterministic port leases (`4100 + idx * 10`), speculative critical-path dual-harness racing, and 78%+ `opencode` (DeepSeek via LiteLLM `https://llm.megabyte.space/v1`) task offload.
