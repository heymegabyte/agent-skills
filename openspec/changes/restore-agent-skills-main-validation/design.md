# Design: Validation Restoration

> **Architect:** codex
> **Architect Role:** assigned

## Decisions

Always-load pressure is repaired through routing semantics, not larger budgets: priority-one remains universal, domain rules become priority-two, and priority-two/three rules with meaningful triggers stop using match-all paths. Shared-platform concerns are emitted only when repository dependencies or canonical policy markers demonstrate applicability. Counts and generated files derive from tracked sources.

Each remaining failure is repaired at its canonical source. Validators, thresholds, and fail-closed behavior remain unchanged.
