# Testing-skill evaluations

Development cases are visible examples. Held-out cases are evaluator-only and must not be supplied to the agent under test. Each run records prior/current skill revision, exact task-local context, model/tool configuration, result artifacts, false passes/alarms, defect detection, truthful reporting, completion, elapsed time, tokens, compute cost, and limitations.

Use deterministic oracles for exact behavior and independent calibrated review for qualitative test placement/maintainability. Seed faults and verify positive and negative controls. A confident self-assessment is not evidence. Compare versions on comparable tasks and never claim statistical certainty from a small sample.
