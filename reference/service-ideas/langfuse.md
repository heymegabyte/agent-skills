# Langfuse Cloud — service-idea catalog (LF-01…30)

30 reusable AI-observability improvement HYPOTHESES absorbed from REVISION-2 Appendix D2 (research date 2026-10-28). Reusable METHODS to assess against each project's real evidence — NOT claims about any account, NOT live product state (§23.9 / §19.3). Pointed to by `rules/observability-ops-supervisor.md`. Per-project applicability/owner/status; full per-idea detail lives in the REVISION-2 spec.

## Global constraints (apply to every LF idea)

- Langfuse Cloud announced removal of remaining LEGACY APIs / trace-ingestion on **2026-11-16** — recheck compat + use supported current SDKs / OTLP; don't copy stale v3 examples. Node auto-instrumentation ≠ Workers / unsupported subscription CLIs.
- Dedupe LOGICAL generations — never record one model call twice (app instrumentation + gateway export); a judge score ≠ truth; cost ≠ revenue.
- No secrets / customer content / raw emails / repo bundles in traces; mask at EVERY exporter (a Langfuse hook doesn't sanitize a Sentry copy); respect ingestion delay + region + retention + plan.

## Adapter notes (§23.10 — verify against installed versions)

- Audit current ingestion PLUS read/query/export/evaluation APIs before the 2026-11-16 legacy removal; migrate deprecated trace-level evaluators. Use supported observations/scores/metrics APIs with bounded windows, cursor pagination, limited dimensions. SDK-major ≠ server-major ≠ API-version.

## Ideas

- **LF-01** — Close AI-execution visibility gaps *(coverage)*: instrument supported entry points with stable task/run/version context, ONE export path per generation; reconcile vs app counters. *Verify:* trace a representative request per runtime → correct parentage/completion/usage, no dup generation. Src: compatibility, public-api, trace-ids.
- **LF-02** — Promote prompts by measured outcomes *(prompt release)*: compare candidate vs baseline on a frozen dataset, canary the winner, keep rollback. *Verify:* objective task success + quality/cost/latency guardrails. Constraint: labels mutable + caches serve prior version → record the actual version; ONE authoring authority. Src: prompt-management/data-model, experiments.
- **LF-03** — Route models by quality-adjusted cost *(economics)*: benchmark eligible routes, pick cheapest meeting quality+latency, keep escalation. *Verify:* cost per verified success + failure/tail guardrails on held-out + rollout. Constraint: estimates may omit subscription/custom charges; don't compare across case mixes. Src: token-and-cost, metrics-api, experiments.
- **LF-04** — Remove low-value prompt/context tokens *(context efficiency)*: trace-guided ablation of redundant instructions / irrelevant retrieval; update router/pack. *Verify:* lower input cost+latency, no regression in correctness/recall/authz. Constraint: inspect exact source; store metadata/redacted excerpts, not whole repos. Src: token-and-cost, experiments, metrics-api.
- **LF-05** — Improve time to first useful response *(streaming UX)*: optimize retrieval/setup + streaming boundaries, or a lower-latency route with progress feedback. *Verify:* p50/p95 time-to-first-token + first-useful + success + cancel. Constraint: first token may be filler — instrument a useful-result milestone. Src: observations-api, metrics-api.
- **LF-06** — Shorten the AI workflow critical path *(agent latency)*: parallelize only independent steps, cache safe repeats, drop transforms. *Verify:* end-to-end p95 + verified success, NOT sum-of-child-spans. Constraint: parallel spans overlap → summing overstates; protect deps/budgets/cancel/side-effect order. Src: trace-ids, observations-api.
- **LF-07** — Improve tool/skill selection *(agent routing)*: curate misrouted examples, refine skill descriptions/router. *Verify:* routing precision/recall + task success on held-out ambiguous/adversarial. Constraint: tool-call presence ≠ correct outcome; reuse Promptfoo, write scores to Langfuse. Src: observations-api, datasets, scores-via-sdk.
- **LF-08** — Stop unproductive agent loops *(autonomy control)*: detect repeated no-progress → checkpoint / change-strategy / ask. *Verify:* inject loop → bounded spend/attempts + checkpoints, no premature stop of legit long tasks. Constraint: Langfuse analytics ≠ a synchronous budget enforcer — cap in the dispatcher. Src: token-and-cost, observations-api, sessions.
- **LF-09** — Provider fallback preserves quality *(resilience)*: bounded compatible fallback routes preserving capabilities/context/structured-output. *Verify:* simulate outage → recovery rate + quality + elapsed + total-attempt cost. Constraint: fallback changes behavior/data-handling; dedupe logical generations. Src: observations-api, token-and-cost, experiments.
- **LF-10** — Improve retrieval relevance before enlarging context *(retrieval quality)*: evaluate query-rewrite/chunking/ranking/filters; fix the responsible component. *Verify:* recall/precision on labeled + grounded task success + token cost. Constraint: enforce tenant access BEFORE retrieval; test stale/unauthorized-doc exclusion. Src: observations-api, datasets, evaluation/overview.
- **LF-11** — Reduce unsupported claims + broken citations *(factual reliability)*: score support + citation validity, isolate failure classes, improve retrieval/response reqs. *Verify:* held-out unsupported-claim rate + citation resolvability, keep coverage. Constraint: a judge ≠ truth; managed code evaluators can't fetch URLs — net-check in a runner. Src: llm-as-a-judge, code-evaluators, scores-via-sdk.
- **LF-12** — Enforce structured-output + tool-arg contracts *(contract correctness)*: compact deterministic checks + prompt/model/API selection; validate at the boundary before side effects. *Verify:* first-pass schema validity + semantic acceptance + negative/boundary. Constraint: JSON-valid ≠ domain-correct; managed code evaluators have no net/pkgs + 2s limit. Src: code-evaluators, scores-via-sdk.
- **LF-13** — Calibrate clarify/refusal behavior *(interaction)*: rubric separating actionable-assumption / necessary-clarify / justified-refusal / mistaken-refusal; tune routing. *Verify:* unnecessary-question + refusal rates alongside unsafe-action + wrong-assumption on held-out. Constraint: don't cut refusals by weakening authz/safety; need human-labeled edges. Src: annotation-queues, score-analytics, datasets.
- **LF-14** — Resist instructions in retrieved content *(untrusted context)*: eval instruction-precedence + correct citing + no treating-retrieved-as-authz. *Verify:* synthetic canaries → unauthorized-tool-call attempts + completion on paired benign/adversarial. Constraint: isolated fixtures, no live secrets; Langfuse ≠ a runtime permission boundary. Src: datasets, llm-as-a-judge, scores-via-sdk.
- **LF-15** — Verify AI tenant/permission boundaries *(multitenant confidentiality)*: regression cases for resource-enum / shared-memory-contam / wrong-account-tool / tenant-config-mix. *Verify:* deterministic denial/isolation + zero synthetic cross-tenant leak. Constraint: no finite suite proves universal isolation — enforce in code; no tenant creds in datasets. Src: datasets, code-evaluators, sdk/advanced.
- **LF-16** — Improve multilingual task quality *(i18n)*: find language-specific failures (terminology/format/locale/completion); adapt where evidenced. *Verify:* task success + rubric by language with matched samples + native review. Constraint: don't infer identity from language; an English-only judge mis-ranks. Src: datasets, annotation-queues, metrics-api.
- **LF-17** — Evaluate image/audio/document workflows *(multimodal)*: targeted checks for image-understanding / alt-text / transcription / extraction / review. *Verify:* task accuracy + human-reviewed quality across media with exact media/model/prompt versions. Constraint: multimodal dataset experiments need a supported SDK; confirm asset rights. Src: datasets, evaluation/overview.
- **LF-18** — Measure complete multi-turn success *(conversation)*: session-linked traces → where intent is lost/stalls; improve state/next-step/recovery. *Verify:* verified session completion + turns-to-completion + correction freq, don't penalize necessary clarify. Constraint: session grouping needs propagated IDs; don't publish sessions public. Src: sessions, scores-via-sdk.
- **LF-19** — Repair context loss at handoffs *(multi-agent)*: compact acceptance/context/evidence handoffs; receivers validate inputs. *Verify:* handoff omissions + duplicated investigation + end-to-end acceptance on cross-repo. Constraint: correlate via trace context / explicit links; scoped context, no secret propagation. Src: trace-ids, sessions, scores-via-sdk.
- **LF-20** — Feedback → a specific AI fix *(customer feedback)*: route low-rated/corrected outputs to a failure class, fix prompt/retrieval/tool, keep a regression. *Verify:* repeat-failure + user-rated helpfulness post-change with response-rate/bias. Constraint: implicit actions (copy) are ambiguous — not auto-success; scoped score key, prevent spoofing. Src: user-feedback, scores-via-sdk.
- **LF-21** — Human review on uncertain/consequential *(review efficiency)*: annotation queues for judge-disagreement / rare-class / high-impact + a random control. *Verify:* reviewer agreement + corrections/hour + rare-case coverage. Constraint: reviewers get redacted material; targeted queues distort population estimates — keep a random sample. Src: annotation-queues, score-analytics.
- **LF-22** — Calibrate judges + detect drift *(evaluation validity)*: tune rubrics vs adjudicated examples, separate objective/subjective, revalidate after any judge/model change. *Verify:* confusion-matrix/agreement + FP/FN on a held-out calibration set. Constraint: correlation ≠ correctness; record resolved evaluator/model versions. Src: score-analytics, llm-as-a-judge, annotation-queues.
- **LF-23** — Production failures → regression corpus *(continuous learning)*: deduped dataset items covering the failure + nearby success/negative; owner + expected outcome. *Verify:* the new test fails former behavior, passes post-fix; track recurrence. Constraint: keep a held-out set; version schemas + expectations separately. Src: datasets, annotation-queues.
- **LF-24** — Block AI regressions before release *(release assurance)*: run the Promptfoo/runner suite + linked Langfuse experiments; enforce quality/safety/cost/latency gates. *Verify:* a seeded bad change fails the gate, a valid one passes reproducibly with evidence. Constraint: no uncalibrated-judge-average as the sole gate; bounded representative suites. Src: evaluation/overview, experiments, scores-via-sdk.
- **LF-25** — Reproducible + comparable experiments *(evidence integrity)*: an immutable experiment manifest; preserve baseline/candidate outputs + score provenance. *Verify:* rerun a sample + explain variance; reject mismatched-input comparisons. Constraint: GET dataset defaults to latest unless versioned; resolve moving labels/aliases. Src: datasets, prompt-management/data-model, experiments.
- **LF-26** — Connect AI spend to verified value *(business economics)*: join usage/cost + scores via approved opaque IDs to authoritative outcomes. *Verify:* controlled cohorts/experiments reporting denominator + delayed outcomes + uncertainty. Constraint: Langfuse cost ≠ revenue; no customer content / unrestricted user joins to marketing. Src: token-and-cost, metrics-api, user-feedback.
- **LF-27** — Detect quality gaps across cohorts *(service quality)*: scores by feature/plan/environment/task-characteristic; fix route/fallback/impl preserving entitlements. *Verify:* matched success + tail latency across cohorts before/after + sample sizes. Constraint: no sensitive inferred traits; high-cardinality Metrics grouping is limited. Src: metrics-api, score-analytics.
- **LF-28** — Resilient + auditable prompt retrieval *(runtime availability)*: prefetch / approved-fallback, control TTL, test rollout/rollback during an outage. *Verify:* empty + stale-cache failures → an approved prompt runs or fails clearly, version preserved. Constraint: caching ≠ full uptime; a stale/fallback prompt must still meet the current contract. Src: prompt-management/caching, guaranteed-availability.
- **LF-29** — Control eval spend without losing coverage *(eval economics)*: deterministic checks first, stratified judge sampling, bounded backfills, budgets for rare-critical. *Verify:* cost per detected regression + required coverage + queue delay; no self-evaluation recursion. Constraint: managed judges run in Langfuse infra with the configured provider — verify destination; unscored ≠ passing. Src: evaluation/online, core-concepts, code-evaluators.
- **LF-30** — Prevent confidential context leaking via telemetry *(data governance)*: export-stage redaction + allowlists across first + third-party; scope projects/keys; validate deletion/retention. *Verify:* synthetic prohibited values reach NO exporter + required evidence stays usable. Constraint: a Langfuse mask does NOT sanitize a second exporter's copy; sampling ≠ redaction. Src: sdk/advanced, public-api.
