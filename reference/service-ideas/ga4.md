# Google Analytics 4 — service-idea catalog (GA-01…30)

30 reusable web/marketing-analytics improvement HYPOTHESES absorbed from REVISION-2 Appendix D4 (research date 2026-10-28). Reusable METHODS to assess against each project's real evidence — NOT claims about any account, NOT live product state (§23.9 / §19.3). Pointed to by `rules/observability-ops-supervisor.md`.

## Global constraints (apply to every GA idea)

- **Customer-analytics tenant boundary (loop invariant):** never put owner GA IDs on customer-generated sites by default; customer sites use tenant-owned properties/containers. Missing perms / dims / rows / samples / processing-lag = UNKNOWN, never zero or healthy.
- No PII / secrets / sensitive attributes / personal identifiers in payloads; sanitize URLs/titles/search/forms before dispatch (hashing PII is NOT an exception). Consent applies to browser + server collection.
- Account reads ≠ writes; publication targets an explicitly authorized container/env/version with recorded evidence. Reuse shared event contracts (no duplicate GA4/GTM/PostHog producers). Budget/price/content/access/privacy/destructive-filter changes need existing authorization.

## Adapter notes (§23.10 — verify against installed versions)

- Budget by property + API project; request quota info where supported. Distinguish collection LIVENESS from mature reporting — intraday reports lag and processed attribution revises; do NOT turn an immature hourly dip into a product incident without independent evidence.

## Ideas

- **GA-01** — Make business outcomes the measurement contract *(strategy)*: map meaningful outcomes (first deploy / qualified lead / paid purchase) to stable key-events; retire vanity KPIs after dependency review. *Verify:* replay success+fail journeys → event only on the defined outcome + reporting after processing. Constraint: not every click a key-event; absent events = unknown not zero. Src: analytics/9322688, 12229528.
- **GA-02** — Remove the largest onboarding abandonment step *(onboarding)*: investigate a credible drop in an ordered funnel (entry/device/new-vs-returning), simplify copy/validation/default/nav. *Verify:* browser-test the repaired journey + mature-cohort completion with a fixed denominator. Constraint: open vs closed funnel deliberately; low-volume inconclusive. Src: 9327974.
- **GA-03** — Shorten time to first useful result *(activation)*: identify the slowest activation milestone, test defaults/guided-setup/async-progress. *Verify:* timers exclude retries/idle; lower duration without lowering completion. Constraint: numeric/bucketed duration not user content; register custom metrics first. Src: event-parameters, 14240153.
- **GA-04** — Trial→paid without hiding friction *(monetization)*: find value-miss vs plan-confusion vs checkout-friction from trial/activation/pricing/paid events. *Verify:* test upgrade/downgrade/cancel + qualified trial cohorts after the window. Constraint: don't fabricate subscription state from pageviews; payment backend authoritative. Src: 9327974, 12229021.
- **GA-05** — Find behavior tied to durable retention *(retention)*: compare retained vs non-retained to prioritize repeat-use / reminders / return-paths. *Verify:* fixed cohort windows + validate on new cohorts or a controlled experiment. Constraint: GA cohort exploration is device-based (no User-ID); association ≠ cause. Src: 9670133.
- **GA-06** — Fix navigation loops/dead-ends *(nav)*: reproduce the suspected loop; improve IA / back-nav / deep-links / recovery. *Verify:* browser-test the full route sequence + mature path/funnel after release. Constraint: paths span sessions; GA doesn't reveal the root cause alone. Src: 9317498.
- **GA-07** — Unsuccessful site search → better discovery *(search)*: synonyms/categories/empty-recovery/missing-content for repeated unsuccessful intents. *Verify:* representative queries vs the search backend + result-selection/next-step. Constraint: never send raw search text (PII/secrets); disable/sanitize auto search-term; coarse categories. Src: 9216061, 6366371, event-parameters.
- **GA-08** — Prioritize device/browser regressions *(compat)*: reproduce segment gaps on real configs; fix input/layout/compat/loading. *Verify:* targeted browser/viewport + post-release completion stabilizes. Constraint: segment diffs may = traffic mix; don't infer Web Vitals from engagement. Src: api-schema, 9327974.
- **GA-09** — Reduce lead-form abandonment *(forms)*: fix the largest avoidable error / unnecessary field + feedback/continuation from form-start/step/validation-category/accepted-lead events. *Verify:* test server-reject/dup-submit/keyboard/accepted-lead + completion by form version. Constraint: no entered values/emails/names/messages; a browser-submit ≠ accepted. Src: 9216061, event-parameters, 6366371.
- **GA-10** — Improve product/template discovery *(merchandising)*: change ranking/category/previews/comparison for high-demand items failing to progress. *Verify:* verify item/list IDs + the revised flow + qualified downstream. Constraint: ecommerce events only when semantics fit; stable item IDs. Src: ecommerce, validate-ecommerce.
- **GA-11** — Remove checkout-step friction *(checkout)*: improve pricing clarity/methods/recovery/validation on the weakest transition. *Verify:* test success/fail payment / retry / delayed-confirm / returning + mature step conversion. Constraint: no card/bank/billing data; the processor confirms payment. Src: ecommerce, 9327974.
- **GA-12** — Reconcile reported revenue vs real transactions *(revenue data quality)*: find dup/missing purchases, empty/reused IDs, wrong currency, inconsistent value; repair collection. *Verify:* controlled txns+retries reconcile known test totals + matured prod within tolerances. Constraint: web-stream purchase dedupe ≠ app streams; no exactly-once; txn IDs non-PII. Src: 12313109, validate-ecommerce.
- **GA-13** — Detect refund-driven quality problems *(post-purchase)*: investigate products/paths with credible refund concentration; improve expectations/fulfillment. *Verify:* full+partial refund reporting + correct txn linkage + subsequent refund-rate. Constraint: no raw complaints/customer info in GA; partial refunds need idempotency; GA ≠ accounting. Src: ecommerce, 12313109.
- **GA-14** — Test promotions by incremental value *(promotions)*: compare placement/offer, keep promotions improving business outcomes not clicks. *Verify:* verify promo/item attribution + an experiment or mature cohorts. Constraint: don't infer incrementality from attributed revenue; no personal coupon IDs. Src: ecommerce, integration.
- **GA-15** — Rank acquisition by retained value not volume *(growth econ)*: prioritize sources attracting durable customers; investigate high-volume low-value + landing mismatch. *Verify:* reconcile attribution scope + costs + mature cohort windows before a budget shift. Constraint: net value from authoritative costs not GA revenue; budget changes = proposals. Src: 9947257, 9358801.
- **GA-16** — Keep attribution interpretations consistent *(marketing)*: separate acquisition / visit / credited-outcome; fix dashboards mixing scopes or implying cause. *Verify:* validate each report's dims/metrics + reproduce a known journey under the recorded model. Constraint: model changes affect event-scope differently; historical credited outcomes revise. Src: 11080067, 10597962.
- **GA-17** — Repair campaign tagging/source fragmentation *(campaign ops)*: standardize UTM/naming, fix missing/conflicting tags, document legit direct traffic. *Verify:* validate generated links + controlled visits + classification after processing. Constraint: no PII/secrets in campaign values; not all direct = erroneous. Src: 11080067, event-parameters.
- **GA-18** — Choose SEO by landing-page outcomes *(SEO)*: prioritize pages with search opportunity + poor qualified outcomes; improve intent/content/internal-linking. *Verify:* verify indexing separately + mature search+GA windows with compatible groups. Constraint: Search Console has its own lag + limited join dims + top-rows; not in GA Data API — use the authorized SC API. Src: 10737381, webmaster-tools searchanalytics/query.
- **GA-19** — Invest in content advancing a journey *(content)*: improve weak sections / next-step links / examples on content attracting the right visitors but not helping them progress. *Verify:* event semantics + useful-outcome rates after a scoped editorial experiment. Constraint: default scroll = 90% threshold not reading-depth; engagement-time ≠ comprehension. Src: 9216061, api-schema.
- **GA-20** — Improve docs/self-service support *(support)*: repair unclear docs / missing troubleshooting + contextual links from docs-visits + resolution feedback + aggregate support-contact. *Verify:* run the procedure end-to-end + resolution signals + aggregate demand. Constraint: no ticket text/emails/history in GA; contact reduction ≠ success. Src: 12229021, 9317498, 6366371.
- **GA-21** — Use trustworthy experiment exposure data *(experimentation)*: connect the existing experiment engine to GA reporting, evaluate meaningful changes. *Verify:* assignment consistency + exposure timing + sample ratios + outcome windows + independent stats. Constraint: GA ≠ the randomization engine; no auto-winner from a short noisy readout; maintain consent. Src: integration, 14240153.
- **GA-22** — Repair cross-domain journey continuity *(cross-domain)*: audit shared tagging/config/redirects/linker across approved related domains. *Verify:* browser-test an authorized related-domain journey + session/source continuity, no dup events. Constraint: don't stitch unrelated customers/tenant sites; prefer Admin config; confirm shared purpose + consent. Src: cross-domain.
- **GA-23** — Make SPA page/screen reporting accurate *(app nav)*: pick ONE auto or explicit virtual-pageview strategy; fix stale location/referrer or dup pageviews. *Verify:* test initial-load / push-replace / back-forward / hash / reload vs expected counts. Constraint: no overlapping collection paths; sanitized canonical URLs; verify the actual framework nav. Src: single-page-applications.
- **GA-24** — Control event-taxonomy/cardinality debt *(governance)*: consolidate naming variants, replace per-session IDs / raw URLs with bounded categories. *Verify:* validate the new schema + report compat + loss-to-other/ambiguity improve without losing signals. Constraint: don't delete unique historical meaning blindly; not a custom dim per param; thresholded ≠ exact. Src: 14240153, 12229528, reporting-data-expectations.
- **GA-25** — Understand consent-related coverage honestly *(privacy)*: detect broken consent transitions, distinguish measurement loss vs business change, improve consent-UX correctness. *Verify:* test grant/deny/withdraw/returning + region defaults with network/storage evidence. Constraint: consent rate ≠ an optimization objective; modeled ≠ observed; no exact universal coverage ratio. Src: consent, consent-debugging.
- **GA-26** — Keep synthetic/staff traffic from distorting decisions *(data hygiene)*: separate test traffic or evaluate filters in testing mode before a scoped exclusion. *Verify:* matching test events + non-matching real traffic + expected labels before an authorized filter. Constraint: active GA data exclusions are PERMANENT for incoming data; don't filter broad ranges without evidence. Src: 13296662.
- **GA-27** — Make the intake lag- + quality-aware *(reporting reliability)*: label provisional/partial/unknown, defer premature comparisons, re-read mature windows, investigate real ingestion regressions. *Verify:* simulate delayed/empty/thresholded/API-failure → no false product incident. Constraint: no-row ≠ zero; metadata/methods vary by version. Src: 11198161, ResponseMetaData, reporting/data/v1.
- **GA-28** — BigQuery only for what reports can't answer *(warehouse)*: authorized scoped exports for reproducible aggregate joins / longer analysis; materialize only needed views. *Verify:* reconcile daily exports vs expected schema + documented GA-report diffs + cost bounds + access. Constraint: standard daily export is volume-limited; streaming best-effort/incomplete; raw ≠ modeled; no new paid infra without authz. Src: 9358801, 13578783.
- **GA-29** — Mature anomalies → prioritized work *(opportunity discovery)*: a deduped hypothesis with impact/confidence/segment + a concrete investigation/experiment from a seasonally-comparable validated series. *Verify:* backtest thresholds + min-volume/cooldown + outcome comparison. Constraint: the native insight UI has no assumed public retrieval API; use Data API aggregates; no 20-alerts-for-one-outage or auto-spend. Src: 9443595, 9517187, reporting/data/v1.
- **GA-30** — Maintain correct property ownership/config *(tenant governance)*: a tenant-owned site→property mapping + audit drift/access + least-privilege corrections via the Admin API. *Verify:* test wrong-tenant/unknown-ID rejection + map known sites + confirm an approved change via a fresh read. Constraint: never owner GA IDs on customer sites by default; read-only for monitoring; no auto invites/deletion/retention changes. Src: config/admin/v1, admin/v1/quotas.
