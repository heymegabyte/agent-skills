# Promptfoo — service-idea catalog (PF-01…30)

30 reusable AI/agent-evaluation improvement HYPOTHESES absorbed from REVISION-2 Appendix D6 (research date 2026-10-28). Reusable METHODS to assess against each project's real evidence — NOT claims about any account, NOT live product state (§23.9 / §19.3). Pointed to by `rules/ai-agent-supervisor.md`.

## Global constraints (apply to every PF idea)

- A green judge score / passing assertion / plausible answer ≠ the intended result — prefer deterministic checks + independent state/effect verification; calibrate judges before using them as gates.
- No secrets / raw customer payloads to hosted generation or judges; never real credentials as canaries; route sensitive data deliberately (`--no-share` ≠ all-local; `--safe-mode` ≠ an execution sandbox).
- Bound eval work: cap tests / targets / repeats / turns / concurrency / timeout / duration / provider spend; cost/latency assertions evaluate COMPLETED work — they are not hard runtime enforcement.

## Adapter notes (§23.10 — verify against installed versions)

- Reuse the supported Cloudflare AI-Gateway routing + Langfuse integration + current trace retrieval before writing adapters; inspect/adapt the maintained upstream evaluation/provider/red-team skills. Disable response caching for fresh latency/variance/trajectory tests (account separately for provider prefix caching). Verify actual spans + external effects. Local CLI execution can still call hosted generation/judges.

## Ideas

- **PF-01** — Real AI failures → a stable regression corpus *(production learning)*: minimal reproducible cases with +/- controls, stable IDs, source evidence, issue links. *Verify:* old behavior fails, corrected passes the same cases; holdout no regression. Constraint: separate train/holdout; pin resolved Langfuse prompt versions + dataset snapshots; no sensitive prod inputs without minimization. Src: integrations/langfuse, agent-skill.
- **PF-02** — Choose models by useful-outcomes per $ *(routing/economics)*: run a representative suite vs candidate configs through the existing gateway; pick a task-specific policy. *Verify:* paired results + cost-per-success with fresh repeats for variance. Constraint: not a tiny convenient benchmark; no silent version swaps; cost/latency assertions ≠ hard enforcement. Src: getting-started, providers/cloudflare-gateway.
- **PF-03** — Keep AI data compatible with canonical contracts *(structured output)*: validate structured outputs + business invariants vs TypeSpec/repo JSON schemas; fix prompts/adapters. *Verify:* known malformed + semantically-invalid fixtures fail; consumers accept correct. Constraint: valid JSON ≠ correct; generate schemas from the authoritative contract. Src: evaluate-json, expected-outputs/javascript.
- **PF-04** — Improve tool selection + argument accuracy *(tool use)*: eval + repair tool descriptions / routing / param-extraction across required + forbidden choices. *Verify:* tool-call precision/recall + schema/business-arg correctness on unseen. Constraint: provider tool formats differ (test the deployed adapter); a proposed call ≠ executed. Src: configuration/tools, expected-outputs/deterministic.
- **PF-05** — Verify required agent action order *(workflow correctness)*: trajectory arg/sequence assertions; fix agents skipping prereqs or using the wrong object. *Verify:* out-of-order + wrong-object traces fail; authorized trajectories pass. Constraint: require real trace spans + ordering semantics; a trace ≠ server-side authz; a missing trace ≠ pass. Src: tracing, expected-outputs/deterministic.
- **PF-06** — Reject plausible completion claims without work *(completion truthfulness)*: eval outcome-attainment, prevent success reports on planned/partial/failed work. *Verify:* a convincing false-success fails; completed artifacts + state transitions pass objective + a calibrated goal rubric. Constraint: prefer independent state checks over the agent's narrative; keep deterministic checks for critical outcomes. Src: model-graded, expected-outputs/javascript.
- **PF-07** — Prevent duplicate side effects after interruption *(durability)*: mock providers injecting post-write timeouts / dup-delivery / lost-ack; eval reconcile-unknown + reuse-logical-op-ID before retry. *Verify:* the persistent ledger has ONE intended effect + a recoverable unknown. Constraint: isolated mock/sandbox accounts, no real dup publish/payment; dedupe in the product, not Promptfoo. Src: providers/http, usage/node-package.
- **PF-08** — Improve retrieval coverage *(RAG recall)*: compare chunking/indexing/search/rerank for missed required evidence. *Verify:* recall@k + calibrated context-recall, no latency/permission regression. Constraint: eval retrieval separately from generation; missing corpus = a content gap, don't invent. Src: guides/evaluate-rag.
- **PF-09** — Reduce unnecessary retrieval context *(RAG efficiency)*: tune top-k / dedupe / rerank / selection removing distractors, keep required support. *Verify:* lower context tokens/cost + noninferior recall + answer correctness. Constraint: context-relevance measures minimal-needed; don't strip qualifications/exceptions/provenance. Src: model-graded/context-relevance.
- **PF-10** — Reduce unsupported statements + fabricated citations *(RAG grounding)*: test claim-support + citation-existence; fix grounding / retrieval-to-citation mapping. *Verify:* invented claims/refs fail; supported claims keep coverage + resolve to source. Constraint: context-faithfulness depends on the judge + misses implicit; grounding ≠ source-true/current. Src: context-faithfulness, red-team/plugins.
- **PF-11** — Verify when the agent must refresh current info *(research freshness)*: eval detect-stale + consult-allowed-sources + update. *Verify:* freshness-sensitive fixtures show a lookup + current conclusion; stable facts trigger no wasteful search. Constraint: pinned snapshots for regression + a separate live-currentness check; a search-rubric needs a search-capable grader. Src: model-graded/search-rubric.
- **PF-12** — Validate context compression + skill routing *(context efficiency)*: test smaller packs + selective skill-load preserving constraints/contracts/cited-source. *Verify:* lower input tokens + noninferior success + no lost mandatory instruction / wrong-skill. Constraint: a skill-used assertion = reported metadata, not correct application; keep cold-context in the holdout. Src: expected-outputs/deterministic, configuration/reference.
- **PF-13** — Multi-turn clarify without needless questions *(conversational UX)*: eval asks-only-material + preserves-answers + completes-when-enough. *Verify:* more completed scenarios + fewer unnecessary clarify turns. Constraint: cap simulated turns, isolate state; Simulated User uses hosted generation by default (configure privacy). Src: providers/simulated-user.
- **PF-14** — Preserve user corrections across long tasks *(instruction following)*: versioned multi-turn where the user changes a constraint / corrects / asks status; fix memory discarding the objective or treating status as cancel. *Verify:* final artifacts satisfy the latest compatible constraints + keep the original objective; conflicts explicit. Constraint: explicit expected state transitions, not just similarity; keep authoritative vs quoted/untrusted separate. Src: configuration/prompts, simulated-user.
- **PF-15** — Improve localized answers + commercial details *(i18n)*: native-reviewed locale fixtures (dates/currencies/units/names/plurals); fix locale prompts/format/translation that changes meaning or misstates terms. *Verify:* exact numeric/date invariants + calibrated native checks per locale. Constraint: translation similarity ≠ correct; sample + report each locale; multilingual red-team costs more. Src: configuration/prompts, red-team/configuration.
- **PF-16** — Useful AI explanations + a11y text *(accessible communication)*: fixtures for plain-language / descriptive-links / alt-text / nonvisual-guidance; fix outputs omitting meaning or relying on visual-only cues. *Verify:* human-calibrated comprehension/description rubrics + factual completeness. Constraint: Promptfoo evaluates content, doesn't certify UI a11y; give the grader the real image/source. Src: guides/llm-as-a-judge, model-graded.
- **PF-17** — Screenshot/doc-grounded decisions *(multimodal)*: controlled screenshots/docs with known states/text/absent-elements; fix models inventing controls / missing content / misreading. *Verify:* more correct grounded interpretations + fewer unsupported visual claims on held-out. Constraint: supported image formats + a vision grader; include low-quality/ambiguous; an image-description ≠ a successful browser action. Src: providers/openai, model-graded.
- **PF-18** — Raise generated article/script quality *(content quality)*: eval factual-coverage / structure / dup / unsupported-claims / attribution before render/publish. *Verify:* fabricated/repetitive drafts fail; approved meet fact checks + an editorial rubric. Constraint: supply source to graders + an overlap check; a judge ≠ copyright clearance; eval-approval ≠ publication authorization. Src: integrations/agent-skill, model-graded.
- **PF-19** — Improve coding-agent changes with verifiable repo outcomes *(software eng)*: disposable repo fixtures with task / acceptance-tests / protected-verifier; compare agent changes on real outcomes + missed-reqs + truthful-reporting. *Verify:* independent tests + artifact checks pass without weakening protected tests; bounded cost/time. Constraint: isolated write-capable workspaces + scoped creds; safe-mode ≠ sandbox. Src: evaluate-coding-agents, expected-outputs/javascript.
- **PF-20** — Resist instructions in untrusted content *(injection resilience)*: targeted indirect-injection probes on the actual untrusted input field; fix the trust boundary. *Verify:* allowed tasks complete, injected instructions ignored, no forbidden tool-call / egress / state-change. Constraint: authorized systems + synthetic secrets + controlled destinations; inspect actual effects. Src: red-team/plugins/indirect-prompt-injection, red-team/plugins.
- **PF-21** — Verify account/tenant object boundaries *(authorization)*: controlled identities + owned/unowned IDs across tenant/role/session; test unauthorized read/write incl wrong-object-ID. *Verify:* permitted succeed; unowned remain inaccessible + unmodified, no existence/content leak. Constraint: server-side checks are mandatory even when the model refuses; use real sandbox authz boundaries. Src: red-team/plugins/bola.
- **PF-22** — Prevent sensitive-data leakage via outputs/tools *(privacy/secrets)*: synthetic canary secrets in protected context / logs / another session; eval disclosure/exfil + fix minimization/redaction/tool-authz. *Verify:* canaries absent from unauthorized outputs / tool-args / telemetry / artifacts / cross-session. Constraint: never real creds as canaries; `--no-share` ≠ all-local. Src: red-team/plugins, integrations/agent-skill.
- **PF-23** — Reduce unsafe compliance AND unnecessary refusals *(helpfulness/policy)*: paired allowed/disallowed near the policy boundary with reviewed expected behavior; tune policy + escalation. *Verify:* false-refusal + unsafe-compliance rates SEPARATELY by category with controls. Constraint: a keyword / refusal phrase ≠ grading; deterministic effect checks for action agents. Src: expected-outputs/deterministic, llm-as-a-judge.
- **PF-24** — Prevent invented prices/refunds/commitments *(commercial accuracy)*: versioned official terms + adversarial/ambiguous requests; test answers use current offers + no unauthorized refund/discount/commitment. *Verify:* exact commercial facts match source + out-of-scope → correct escalation without blocking allowed help. Constraint: controlled tools + approved fixtures, no real financial effects; refresh when terms change. Src: red-team/plugins, model-graded/search-rubric.
- **PF-25** — Improve perceived AI speed *(latency UX)*: fresh evals with end-to-end latency + first-useful-output + workload size; optimize prompt/stream/route/sequential while keeping quality. *Verify:* p50/p95 task latency or first-useful budgets on a sufficient fresh sample. Constraint: disable response caching for latency + record prefix-cache separately; a latency-assertion ≠ a timeout. Src: expected-outputs/deterministic, configuration/caching.
- **PF-26** — Bound runaway agent cost + steps *(resource discipline)*: reduce redundant calls + verify stop/checkpoint at the step/time/spend budget. *Verify:* tasks within enforced limits + required success; runaway fixtures terminate safely with a truthful partial. Constraint: the cost assertion needs provider cost + only completed responses; hard caps upstream; count judge/gen/retries/tools too. Src: expected-outputs/deterministic, configuration/reference.
- **PF-27** — Usable AI during dependency failures *(resilience)*: controlled 429 / timeout / unavailable / malformed / partial-stream / tool-error fixtures; verify bounded-retry / fallback / preserved-work / actionable-errors through the deployed path. *Verify:* recoverable cases complete; unrecoverable stop within budget + resumable state, never report success. Constraint: distinguish Promptfoo retries from the SUT's; fault-inject owned sandboxes only. Src: providers/http, configuration/caching.
- **PF-28** — Calibrate graders before release gates *(evaluation validity)*: human-labeled good/bad/borderline/adversarial with source + reasons; compare rubric/judge choices, fix ambiguous criteria, prefer deterministic. *Verify:* agreement + false-pass/fail on held-out; a broken/empty grader is never a pass. Constraint: no model grading itself uncalibrated; control rubric/judge versions + position/order effects. Src: llm-as-a-judge, model-graded/search-rubric.
- **PF-29** — Gate AI changes on reproducible comparative evidence *(release quality)*: candidate + pinned-baseline on the same versioned slice; fast objective + impact-based semantic/red-team; block material regressions / critical failures. *Verify:* export per-case results / failures / cost / runtime / baseline-deltas tied to commit/dataset/prompt/model/grader versions. Constraint: cap tests/targets/repeats/turns/concurrency/timeout/duration/spend; no parallel scheduler; cached ≠ a fresh provider check; `--safe-mode` ≠ a sandbox. Src: usage/node-package, command-line, configuration/reference, agent-skill.
