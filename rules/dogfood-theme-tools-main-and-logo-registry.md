# Dogfood Principle (`@theme.tools#main`), Master Template & Canonical Logo Registry

- **Dogfood Principle (Always Track `heymegabyte/theme.tools#main` Live)**: Always point `@theme.tools/*` / `@theme-tools/*` (`ui.theme.tools`) directly to the latest code on the `main` branch of `heymegabyte/theme.tools` (`/Users/Apple/emdash/repositories/theme.tools/packages/ui/src` locally via Vite `resolve.alias` and `https://github.com/heymegabyte/theme.tools.git#main` in `package.json` & `theme.tools.json`). Even though tracking `main` live may occasionally surface breaking changes early, **it is always better to dogfood everything** so every update to `ui.theme.tools` (including `@theme-tools/ui/coming-soon` `<ComingSoonPage />`) automatically flows into every project when rebuilt.
- **Master `theme.tools` Template in Emdash**: Initialize and assemble websites/apps in Emdash from `heymegabyte/theme.tools/templates/master-site-template`, using `<ComingSoonPage />` from `@theme-tools/ui/coming-soon` for coming-soon surfaces.
